# armanckeser.com

Armanc Keser's personal site and blog.

**Read it at [armanckeser.com](https://armanckeser.com).**

Run it locally with [bun](https://bun.sh):

```bash
bun install
bun run dev
```

- SvelteKit, with posts written as [mdsvex](https://mdsvex.pngwn.io/) `.svx` files in `src/content/writing/`.
- Deployed to GitHub Pages on every push to `main`.
- `/cms` is a studio where Claude and I write posts together, next to the rendered page. [AGENTS.md](AGENTS.md) is its guide.
- Films and books come from my public Letterboxd and Goodreads feeds.

Dev setup, the studio, writing posts, deploying and checks are in [CONTRIBUTING.md](CONTRIBUTING.md).
